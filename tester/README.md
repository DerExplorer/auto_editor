# Тестер роликов

Маленькая локальная страница, чтобы сравнивать тестовые версии монтажа: все ролики играют синхронно, звук — у выбранного, под каждым роликом — время сборки и замеры. Вторая вкладка — план: что уже добавлено и что следует добавить.

## Запуск

```bash
node tester/server.mjs
```

Открыть http://localhost:8765. Нужен только Node 18+; `ffprobe` — чтобы показать сведения о старых роликах без данных о сборке.

Другой порт или папка с роликами: переменные `PORT` и `AUTO_EDITOR_OUT` (иначе берётся `outputDir` из `app/local.json` или папка `output` в корне).

## Откуда данные

Всё лежит в папке с готовыми роликами (`output/`, в git не попадает):

| Файл | Что | Кто пишет |
|---|---|---|
| `tests.json` | список тестов: `name`, `date`, `what` (что нового), `check` (что посмотреть) | Claude после каждого теста |
| `roadmap.json` | `done` (дата, область, текст) и `todo` (область, текст) | Claude, когда что-то сделано или появилась идея |
| `<имя>.mp4` | сам ролик | `npm run render` |
| `<имя>.stats.json` | время этапов (подготовка, план, рендер, громкость), кадр, звук, сколько элементов | `app/scripts/build.mjs` при рендере |

## Управление

- **Пробел** — пауза, **← →** — на 5 с, **, .** — на кадр назад/вперёд, скорость 0,5–2×.
- Клик по ролику — звук переключается на него (янтарная рамка).
- Кнопки с названиями — показать/скрыть версии; выбор запоминается в этом браузере. По умолчанию видны 6 последних.
- «Подробнее» под роликом — время сборки по этапам, сколько секунд рендера уходит на секунду ролика, размер, громкость, музыка, элементы монтажа.
