# auto_editor — правила работы для Claude

Монтажёр вертикальных рилсов на Remotion. Claude здесь — **режиссёр монтажа**: смотрит исходники, пишет описание монтажа (`app/edits/<имя>.json` + текстовый слой субтитров `<имя>.subs.txt`), запускает сборку, проверяет кадры и отчитывается. Код рендера трогать только при необходимости.

## Как проходит работа с роликом

1. Пользователь кладёт видео в свою папку `input` (путь — в `app/local.json`; если файла нет: `npm run setup` в `app/` создаст `~/Desktop/Apps/auto_editor/{input,output}`) и пишет в чате, какие файлы и что сделать.
2. Изучить материал:
   - `ffprobe` — размер и длительность;
   - транскрипция (`python scripts/transcribe.py` или просто первая сборка — кэш в `app/build/cache`);
   - раскадровка ffmpeg (`tile`) — где лицо, какие сцены;
   - смены сцен во вставке: `select='gt(scene,0.25)'`.
3. Написать `app/edits/<имя>.json` (образцы: `apple.json`, `doritos2.json`, `testreels1.json`, `reel2.json`) и **переписать `<имя>.subs.txt` по смыслу** (черновик создаётся автоматически).
4. `npm run build -- edits/<имя>.json` → устранить предупреждения («не влезет в 2 строки»), проверить стоп-кадры (`npx remotion still src/index.ts Edit out.png --frame=N --props=build/<имя>/9x16.props.json --scale=0.4`).
5. `npm run render -- edits/<имя>.json` → ролик в `output`. Проверить кадры уже из готового mp4. Отчёт: путь, что сделано, что упрощено.
6. Не затирать прошлые результаты — новая версия под новым именем, если пользователь не просил перезаписать.

## Стиль (правила пользователя — соблюдать по умолчанию)

**Формат**
- Только вертикаль 9:16 в исходном разрешении. Без логотипа, без полноэкранных заставок в начале/конце.
- Если видео уже нарезано пользователем — авто-нарезку не делать (`"cut": {"removePauses": false, "removeRetakes": false}`).

**Хук**
- Заголовок первые ~3 с, КАПСОМ, слова разного размера (сильнее акцент — крупнее, главное слово — на янтарной плашке).
- Слова въезжают по одному сверху. Если сверху лицо — ставить в средней зоне (`hook.topPct`).

**Субтитры**
- До 2 строк, всегда самый верхний слой. Текущее произносимое слово — янтарное, остальные сплошные белые.
- Без прозрачности, подпрыгиваний, свечения.
- Текстовый слой:
  - маленькие буквы, без точек;
  - цифры цифрами;
  - КАПС целым словом — только сильные акценты;
  - заглавные только где нужно по смыслу (буквы вариантов, имена, бренды), не в начале фразы;
  - варианты: «вариант А. 20%», «А. удвоилась».
- Блоки делить по смыслу: не слишком большие, не рубить мысль.
- Нумерация («номер 4», «вопрос второй») → в месте субтитров только большая цифра: строка `[4] номер 4`.
- Исправлять ошибки распознавания (Whisper путает «Б»/«в», коверкает бренды: Doritos, reels).

**Лицо и безопасные зоны** (`app/docs/reels-safe-zones.webp`, для 1080×1920)
- Никогда не перекрывать лицо. Волосы, верхнюю часть волос — можно.
- Важное — внутри безопасных зон:
  - по бокам ≥70 px (не прижимать к краям — важнее всего);
  - снизу 250 px и полоса подписи ≈76–87% высоты;
  - справа в нижней половине колонка кнопок 170 px.
- Верхние элементы (хук, карточки, плашки) — примерно на 5% сверху или чуть ниже.
- Внизу — лёгкий тёмный градиент под субтитры, не доходящий до лица.

**Камера**
- База всегда 100%.
- Время от времени плавный наезд до ~107%, держать хотя бы пару секунд, плавно вернуть. Без «полётов».

**Графика** (дизайн-система каруселей)
- Шрифты Inter Tight (заголовки) + Inter.
- Цвета:
  - чернила `#111317`, текст `#2B2D33`, фон `#FAFAFA`, серый `#DCDCDC`;
  - один акцент — янтарь `#FFC163` (глубже `#F5A742`);
  - на янтаре только чёрный текст;
  - второго яркого цвета нет.
- Плашки-таблетки с наклоном −3°. У всей графики мягкая размытая тень и скругления.
- Полноэкранная инфографика — действительно на весь экран, смысл выше нижней трети (там субтитры).
- Субтитры не перекрывают важный текст инфографики.

**Видео в рамке** (реклама поверх рассказчика)
- Рамка чуть ниже середины, сразу под подбородком, скруглённая, с оранжевой обводкой `#F5A742` (`inset.borderColor`).
- Пропорции берутся из видео. Звук вставки ~5%.
- Субтитры под рамкой (`underInsetBottomPct`). Когда рассказчик переходит к общей теме — рамка уходит, субтитры поднимаются на её место (`inset.end`).
- Нарезка вставки:
  - резать **только если момент рекламы действительно подкрепляет конкретную фразу**; если реклама монотонная или речь описывает её в целом — пусть идёт непрерывно;
  - **никогда не перематывать назад** на уже показанные кадры (кроме случаев, когда по сценарию «посмотрите ещё раз»);
  - резать только вперёд и только чтобы пропустить заметный кусок (секунды, не доли);
  - склейки ставить на собственные смены сцен рекламы;
  - резать мало и аккуратно.
- Не показывать чёрные кадры/затемнения рекламы (начало, после логотипа).

## Техника

- Команды (из `app/`): `npm run setup`, `npm run doctor`, `npm test`, `npm run build -- edits/x.json`, `npm run render -- edits/x.json`.
- Все времена в edit-файле — привязки к фразам речи: `"Вопрос второй"` или `{"phrase", "nth", "after", "edge": "end", "offsetMs", "clip"}`; `{"ms": 3000}` — точное время.
- Видео, `app/build/`, `app/local.json` в git не попадают. Коммитить и пушить — только когда пользователь попросит.
