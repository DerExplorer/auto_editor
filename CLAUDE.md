# auto_editor — правила работы для Claude

Монтажёр вертикальных рилсов на Remotion. Claude здесь — **режиссёр монтажа**: смотрит исходники, пишет описание монтажа (`app/edits/<имя>.json` + текстовый слой субтитров `<имя>.subs.txt`), запускает сборку, проверяет кадры и отчитывается. Код рендера трогать только при необходимости.

## Как проходит работа с роликом

1. Пользователь кладёт видео в папку `input` в корне проекта (рядом с `app/`; если её нет — `npm run setup` в `app/` создаст `input`, `output`, `sfx`, `music`, `reference`) и пишет в чате, какие файлы и что сделать. Готовые ролики — в `output`. Материалы для внедрения (старый стиль montazh-rills, справочники динамичного монтажа) — `Наработки/`, см. `ЧТО ЗДЕСЬ И ЧТО ВНЕДРИТЬ.md`. План развития проекта — `ПЛАН РАЗВИТИЯ.md` в корне (личный файл, в git не попадает; обновлять статусы шагов, когда шаг сделан).
2. Изучить материал:
   - `ffprobe` — размер и длительность;
   - транскрипция (`python scripts/transcribe.py` или просто первая сборка — кэш в `app/build/cache`);
   - раскадровка ffmpeg (`tile`) — где лицо, какие сцены;
   - смены сцен во вставке: `select='gt(scene,0.25)'`.
3. Написать `app/edits/<имя>.json` (образцы: `apple.json`, `doritos2.json`, `testreels1.json`, `reel2.json`) и **переписать `<имя>.subs.txt` по смыслу** (черновик создаётся автоматически).
4. `npm run build -- edits/<имя>.json` → устранить предупреждения («не влезет в 2 строки»), проверить стоп-кадры (`npx remotion still src/index.ts Edit out.png --frame=N --props=build/<имя>/9x16.props.json --scale=0.4`).
5. `npm run render -- edits/<имя>.json` → ролик в `output`. Проверить кадры уже из готового mp4. Отчёт: путь, что сделано, что упрощено.
6. Не затирать прошлые результаты — новая версия под новым именем, если пользователь не просил перезаписать.

## Стиль клиента (паспорт) — до первого ролика нового клиента

- Порядок и анкета — `docs/style/README.md`. Справочники: ниши и что показывать в кадре кроме человека — `niches.md`; промпты для генерации — `prompting.md`; обложки и аватарки — `covers.md`; палитра — `palette.md`.
- Паспорт клиента — `clients/<имя>/` в корне (в git не попадает): `profile.md` (кто, зритель, стиль, промпты), `brand.json` (палитра, настроение и музыка по умолчанию), `palette.html` (превью).
- Палитра из любимых цветов: `npm run palette -- "#цвет1" "#цвет2" --client <имя>` (первый — главный, или `--accent N`). Цвета словами переводить в hex самому.
- Монтаж по паспорту: `"client": "<имя>"` в edit-файле → цвета графики клиента, его `defaults.mood`/`music`, если в edit-файле не заданы.
- В видео один акцент клиента; остальные его цвета — только обложки, аватарка, промпты. Текст на акценте — `onAccent`. Промпты — на английском, текст (особенно кириллицу) не генерировать, а накладывать самим.

## Стиль (правила пользователя — соблюдать по умолчанию)

**Формат**
- Только вертикаль 9:16, всегда 1080×1920. Без логотипа, без полноэкранных заставок в начале/конце.
- Если видео уже нарезано пользователем — авто-нарезку не делать (`"cut": {"removePauses": false, "removeRetakes": false}`).

**Хук**
- Заголовок первые ~3 с, КАПСОМ, слова разного размера (сильнее акцент — крупнее, главное слово — на янтарной плашке).
- Слова въезжают по одному сверху. Если сверху лицо — ставить в средней зоне (`hook.topPct`).

**Субтитры**
- До 2 строк, всегда самый верхний слой. Текущее произносимое слово — янтарное, остальные сплошные белые.
- Без прозрачности, подпрыгиваний, свечения.
- Текстовый слой:
  - маленькие буквы, без точек;
  - цифры цифрами;
  - КАПС целым словом — только сильные акценты;
  - заглавные только где нужно по смыслу (буквы вариантов, имена, бренды), не в начале фразы;
  - варианты: «вариант А. 20%», «А. удвоилась».
- Блоки делить по смыслу: не слишком большие, не рубить мысль.
- Нумерация («номер 4», «вопрос второй») → в месте субтитров только большая цифра: строка `[4] номер 4`.
- Исправлять ошибки распознавания (Whisper путает «Б»/«в», коверкает бренды: Doritos, reels).

**Лицо и безопасные зоны** (`app/docs/reels-safe-zones.webp`; точная разметка Reels/TikTok/Shorts — `app/docs/safe-zones/`: `safe-zones.json` с прямоугольниками и `overlay.png` для проверки кадров, для 1080×1920)
- Проверка кадра: наложить `overlay.png` (красное — интерфейс, зелёная рамка — безопасно везде, янтарная линия — уровень глаз y=640). Ни одна плашка, карточка или субтитр не должны заходить в красное.
- Общая безопасная область для всех платформ: x 70–1010, y 130–1545. Сверху по центру у TikTok/Shorts вкладки (x 313–762, y 115–216); справа иконки x ≥ 887 начиная с y 960 (у Reels с 1095); снизу с y 1545 — ник, описание, музыка.
- Никогда не перекрывать лицо. Волосы, верхнюю часть волос — можно.
- Важное — внутри безопасных зон:
  - по бокам ≥70 px (не прижимать к краям — важнее всего);
  - снизу 250 px и полоса подписи ≈76–87% высоты;
  - справа в нижней половине колонка кнопок 170 px.
- Верхние элементы (хук, карточки, плашки) — на 9% сверху: одна высота по умолчанию для Reels, TikTok и Shorts.
- Внизу — лёгкий тёмный градиент под субтитры, не доходящий до лица.

**Камера**
- База всегда 100%.
- Время от времени плавный наезд до ~107%, держать хотя бы пару секунд, плавно вернуть. Без «полётов».

**Графика** (дизайн-система каруселей)
- Шрифты Inter Tight (заголовки) + Inter.
- Цвета:
  - чернила `#111317`, текст `#2B2D33`, фон `#FAFAFA`, серый `#DCDCDC`;
  - один акцент — янтарь `#FFC163` (глубже `#F5A742`), у клиента с паспортом — его акцент;
  - на янтаре только чёрный текст (на акценте клиента — `onAccent`);
  - второго яркого цвета нет.
- Плашки-таблетки с наклоном −3°. У всей графики мягкая размытая тень и скругления.
- Полноэкранная инфографика — действительно на весь экран, смысл выше нижней трети (там субтитры).
- Субтитры не перекрывают важный текст инфографики.

**Библиотека графики** (`library/` в корне, в git не попадает)
- `stickers/<группа>/` — 276 анимированных стикеров WebM с прозрачностью (эмоции, жесты, бизнес, знаки, люди, еда, флаги, природа, животные, праздники); список и что не взято — `stickers/СПИСОК.md`. Ставить точечно, под смысл фразы, не как мем.
  - В edit-файле: `"stickers": [{"start": "фраза", "src": "stickers/business/bulb", "side": "left", "y": 0.55, "size": 0.3, "durationMs": 1800}]` — сбоку от лица, не на лице; звук `pop` ставится сам. Фразы — как в распознанной речи (Whisper пишет «крайне бедности», «вакцинированных»), не как в субтитрах.
- `icons/` — `social` (логотипы соцсетей и сервисов: Telegram, Instagram, YouTube, VK, WhatsApp, TikTok… — когда в речи упоминается соцсеть), `people` (белые пиктограммы людей для инфографики), `line` (белые линейные значки), `3d`, `tiles`.
- `iphone/` — полный набор для анимаций с айфоном: `devices` (рамки iPhone 14 Pro / Silver / Space gray, MacBook, статус-бары), `ui` (входящий звонок, клавиатура, iMessage, календарь, переключатель, Face ID, батарея, погода, фото, всплывающее окно AirPods), `call` (кнопки звонка, аватар, обои). **Если в ролике говорят про айфон или действие с телефоном (звонок, сообщение, уведомление, напечатать, открыть приложение) — сначала посмотреть эти файлы**: из них собирается экран телефона, иконки и анимации интерфейса.
  - Анимации с айфоном — по разделу «Анимации» ниже.
- `paper/` — набор для «бумажной» анимации (вырезки из журналов):
  - `letters/<01–26>/<символ>.png` — 26 наборов букв-вырезок, имя файла = символ (`A.png`, `7.png`; знаки: `excl at hash dollar amp caret percent`); где какой символ — `letters/chars.json`, превью — `letters/_index_<набор>.jpg`. Слово собирать из букв разных наборов. Только латиница: русские слова — латинскими двойниками (А В Е К М Н О Р С Т Х У) или рисовать вырезки кодом.
  - `symbols/` — знаки и стрелки; `words/` — английские слова (wow, new, free, yes…); превью `_index_symbols.jpg`, `_index_words.jpg`.
  - `backgrounds/` — видеофоны мятой бумаги (серый вертикальный, белый, чёрный, крафт); `brush-mattes/` — ч/б маски «мазок кисти» для проявления кадра.
  - Звуки бумаги — `sfx/paper/` (шорох, листание, комкание, письмо ручкой).
- `backgrounds/<тема>/` — фоны для b-roll (1080×1920): `minimal`, `color`, `tech`, `science`, `money`, `drama`, `paper`; тема и серьёзность каждого — `backgrounds/INDEX.md`.
  - **Если стиль ролика не простой/минимализм — в ролике хотя бы 1 b-roll на фоне** (`"broll": [{..., "mode": "full", "bg": "backgrounds/money"}]`). Фон выбирать по теме фразы и серьёзности ролика.
  - С фоном: картинка/видео встаёт скруглённой карточкой с тенью в верхние 2/3 (`"fit": "cover"` — на весь экран поверх фона), инфографика — светлой карточкой.
- `overlays/<тема>/` — огонь, искры, стекло поверх кадра (режим screen); список — `overlays/INDEX.md`. Только для усиления эмоции или в хуке, **не больше 1–2 на ролик**, не на спокойных/экспертных роликах. `"overlays": [{"start": "фраза", "src": "overlays/glass/glass-shatter.mp4", "opacity": 0.8, "durationMs": 2000}]`; звук ставится сам.
- `movies/` — кадры из фильмов по эмоциям: `вдохновение`, `энергия`, `напряжение`, `шок`, `грусть`, `спокойно`, `фокус` (работа, мысль, учёба). Моменты до 12 с, горизонтальные, со звуком фильма; что где — `movies/INDEX.md`. Сцены с оружием, кровью, трупами и символикой не нарезаны.
  - **Пополнение**: пользователь кладёт новые нарезки в `library/movies/_source/` → `npm run movies` делает раскадровку `_review/<файл>.jpg` → Claude смотрит её и дописывает моменты в `clips.json` (`from`, `to`, `mood`, `what`) → `npm run movies -- cut` нарезает и обновляет INDEX.md. Насилие и мемы не размечать.
- `transitions/` — 6 переходов, уже 1080×1920 30 к/с. **По умолчанию склейки прямые**; переход — редкость, максимум 1–2 на ролик, только на смене темы. `light-leak-warm`, `light-leak-white`, `light-leak-pink` — засветки (накладывать режимом screen/add поверх склейки); `overlay-pages-warm` — тёплые летящие страницы книги (0,8 с, для темы книг, учёбы, документов); `matte-smoke-reveal`, `matte-brush-wipe` — ч/б маски: белое = новый кадр (brush — для «бумажного» стиля).
- `fonts/` — шрифты для экспериментов (основной стиль пока Inter Tight + Inter); образцы — `_specimen_<группа>.png`:
  - `families/` — полные семейства с кириллицей: Gilroy, Montserrat, Visuelt Pro, Circe, SF Pro Text, Benzin, Good Vibes Pro (курсивы есть у Gilroy, Montserrat, Visuelt);
  - `cyrillic/sans` — читаемые основные; `cyrillic/display` — яркие для хука и акцентов; `cyrillic/script` — рукописные для разбавления;
  - `latin-only/` — без кириллицы: только для английских слов, цифр и брендов.
  - Платные (Gilroy, Visuelt, Circe, SF Pro, Gotham, Helvetica, Cocogoose не брали) — для роликов клиентов на продажу уточнить лицензию; бесплатные: Montserrat, Bebas Neue, Raleway, Noto Sans, Yeseva One, Lemon Milk, League Gothic, Allura, Arizonia, Good Vibes.

**Анимации (моушн-графика)** (решения пользователя 10.10; эталоны — `PhoneDemoFx` в `app/src/PhoneDemo.tsx` и `GdpDemo` в `app/src/GdpDemo.tsx`)
- **Когда делать.** Если в ролике есть место, которое понятнее показать анимацией, — делать её сразу, не спрашивая:
  - действие с телефоном (зайти в настройки, включить режим, открыть приложение, написать, позвонить) → сцена айфона из `Phone.tsx`;
  - цифры: рост, падение, сравнение стран или компаний, «за N лет» → столбцы-платформы, превращение в кривые;
  - страны, регионы, «где в мире» → глобус с выдавленными странами (`GdpDemo.tsx`, d3-geo).
  - Анимация подкрепляет фразу и не заменяет рассказчика надолго: обычно 5–15 с.
- **Как встраивать.** Анимация — отдельная композиция в `app/src/` (сценарий и данные в ней, общие детали — `Phone.tsx`, `anim.ts`), регистрируется в `Root.tsx`. Рендер: `npx remotion render src/index.ts <Композиция> ../output/anim/<имя>.mp4`. В ролик — вставкой на фразу: `"broll": [{"src": "output/anim/<имя>.mp4", "mode": "full", "start": "фраза", "durationMs": 9000}]` (звук анимации глушится, эффекты ставит сборка). Код монтажа (`Edit.tsx`, `build.mjs`) ради анимаций не трогать.
- **Детализация.**
  - Сначала готовое: `library/` (рамки, логотипы, флаги, засветки) и детали из `Phone.tsx` / `anim.ts`. Чего нет — простой рисунок кодом в стиле соседних и сказать пользователю, чтобы добавил в `library/`.
  - Детально — то, на что смотрит зритель (нажимаемая иконка, тумблер, нужный экран, выделенная страна). Второстепенное — заглушки (полупрозрачные квадраты, серые полоски), но живость картинки сохранять: верхние ряды иконок, док, экран нужного приложения — настоящие.
  - С нуля и подробно — только главный визуальный акцент.
- **Динамика — главное** (камера по ключам `camera`):
  - одна плавная кривая через все ключи (`smoothAt` из `anim.ts`) — без остановок на каждом ключе;
  - сдвиг и приближение считаются вместе: цель наезда идёт к центру по прямой, объект не «уходит» перед наездом; наклон — вокруг центра объекта;
  - перед каждым действием — наезд на то, что нажимают или показывают (×1,4–1,6), после — отъезд; переезды ≈0,4–0,45 с, между ними медленный дрейф; на смене этапа — наклон 5–10°;
  - появление и открытие — пружиной с лёгким перелётом; на событии — «поп» (×1,5 → 1) или кольцо свечения; объект слегка «дышит» (покачивание ±2°); быстрые движения (свайп) — лёгкое размытие;
  - темп — около 2 с на действие (≈10 с на 5 действий); слишком быстро и слишком линейно — одинаково плохо.
- **Эффекты — немного.** Засветки из `library/transitions` (не больше 2, opacity ≤ 0,4, не поверх чёрного экрана), блик по стеклу на ключевых моментах, цвет свечения за объектом меняется по событию (цвет приложения или страны), отражение «на полу» — только корпус. Зеркало всей сцены (`box-reflect`) не использовать — рендер вдвое дольше.
- **Данные.**
  - У каждой страны или серии свой цвет — один и тот же во всех сценах: столбец, линия, страна на глобусе, плашка.
  - Столбцы — объёмные платформы (передняя, боковая, верхняя грань) с пружиной и счётчиком числа. Переход в кривые: столбцы сжимаются в точки, точки встают на свой год, линии прорастают в обе стороны (прогноз — пунктиром, зона прогноза подсвечена).
  - Глобус: страны выдавливаются по очереди (высота ≈5% радиуса, у горизонта оседают), плашки с флагом и числом не наезжают друг на друга, глобус поворачивается к следующей группе стран.
  - Источник — мелко внизу кадра. Если цифры сняты с картинки на глаз — сказать пользователю.
- **Стиль.** Есть референс — цвета и фон по нему (для графиков данных — тёмная тема); нет — дизайн-система проекта. Шрифты Inter Tight + Inter (внутри айфона — SF Pro). Всё внутри безопасной зоны.
- **Порядок работы.**
  1. Сценарий и данные; если просто и быстро — сразу динамичная версия, иначе сначала простая, потом динамика.
  2. 6–10 стоп-кадров (`npx remotion still src/index.ts <Композиция> out.png --frame=N --scale=0.3`), склеить ffmpeg `hstack` и посмотреть.
  3. Рендер с замером времени, проверить кадры из готового mp4.
  4. Отчёт: что сделано, что упрощено, время рендера (с на секунду видео) и сравнение с прошлой версией. Новая версия — новый файл, старые не затирать.
  - Ориентир — 1–2 с рендера на секунду видео; намного дольше — найти дорогой эффект (замерить с ним и без) и заменить дешёвым.
- Ресурсы анимаций копируются из `library/` и `sfx/` в `app/public/phone` и `app/public/gdp` (в git не попадают): `npm run anim-assets`.

**Видео в рамке** (реклама поверх рассказчика)
- Рамка чуть ниже середины, сразу под подбородком, скруглённая, с оранжевой обводкой `#F5A742` (`inset.borderColor`).
- Пропорции берутся из видео. Звук вставки ~5%.
- Субтитры под рамкой (`underInsetBottomPct`). Когда рассказчик переходит к общей теме — рамка уходит, субтитры поднимаются на её место (`inset.end`).
- Нарезка вставки:
  - резать **только если момент рекламы действительно подкрепляет конкретную фразу**; если реклама монотонная или речь описывает её в целом — пусть идёт непрерывно;
  - **никогда не перематывать назад** на уже показанные кадры (кроме случаев, когда по сценарию «посмотрите ещё раз»);
  - резать только вперёд и только чтобы пропустить заметный кусок (секунды, не доли);
  - склейки ставить на собственные смены сцен рекламы;
  - резать мало и аккуратно.
- Не показывать чёрные кадры/затемнения рекламы (начало, после логотипа).

**Звук** (`app/scripts/audio.mjs`)
- **Звук по умолчанию — только 2 настройки** (решение пользователя 06.10):
  1. срез низов голоса ниже 80 Гц (гул, «бубнение»);
  2. финальное выравнивание громкости (см. ниже).
- **Шумоподавление и компрессор выключены**: шумоподавление давало «искусственный, ИИшный» звук. Включать только по явной просьбе: `"audio": {"voice": {"denoise": true}}`. Голос совсем без обработки: `"audio": {"voice": false}`.
- Единственная обработка звука по умолчанию — финальное выравнивание громкости готового ролика до −14 LUFS (стандарт Reels/TikTok): подъём уровня, мягкий ограничитель только на редкие пики, точная подгонка loudnorm. Изменить: `"audio": {"lufs": -14}`; отключить: `"normalize": false`.
- Фоновая музыка (по желанию) — **ровный фон одного уровня, не отвлекает** (решение пользователя 07.10): трек заранее выравнивается (мягкий компрессор + нормализация, разброс ≈1–2 LU) и стоит на одном уровне на весь ролик — **без приглушения под голос и подъёма в паузах**, только плавные края. **Трек не нарезается и не зацикливается**: идёт одним цельным куском с начала; громкость меняется только плавно — в начале (2 с) и в конце (2,5 с), и при необходимости на отдельных моментах: `"moments": [{"start": "фраза", "end": "фраза", "db": -6}]`. Трек брать не короче ролика. Уровень — на `relDb` ниже голоса: **по умолчанию −14 дБ** (решение пользователя 10.10, как в TEST3.6: музыка ≈15% высоты волны речи — слышна фоном, слова не перекрывает; −22 было почти не слышно, −7 — на пределе). Настроение сдвигает на ±1 дБ (энергия −13, грусть и спокойно −15). Своё значение: `"music": {"src": "<папка>/<файл>", "relDb": -16}`.
- Музыку выбирать **монотонную**: без резких дропов, пауз и всплесков. Мерило — LRA в `music/tracks.json` (меньше — ровнее; ≤ 6 — годится фоном). Новые треки в `music/` → `npm run music-index`.
- Звуковые эффекты — из библиотеки пользователя `sfx/<категория>/` (папка `sfx/` в корне проекта). Автоматически ставятся на события монтажа:
  - `impact` — старт хука;
  - `hit` — главное слово хука;
  - `pop` — плашка (короткий сухой щелчок);
  - `number` — большая цифра (тональный «бульк»);
  - `click` — окошко инфографики;
  - `whoosh` — появление и уход рамки с видео, карточка, полноэкранная инфографика;
  - `ding` — правильный ответ в карточке.
- Синонимы папок: swoosh/transition, click/bubble, correct/success/notification, boom/hit.
- У каждого типа элемента свой звук; в пуле — 4 заметно разных варианта (разнесены по яркости), чередуются по кругу. Мелкие частые элементы тише: pop и click ×0,6, number и hit ×0,7, ding ×0,8 (поменять: `"sfx": {"categoryVolume": {"pop": 0.4}}`).
- В корне папки категории — этот «пул», только его берут авто-эффекты; `<категория>/_extra/` — запас, авто не берёт (ставить вручную или переносить в пул). Все файлы обрезаны по началу звука и выровнены по пику.
- Категории (разложено из TS PACK 07.10): `pop`, `whoosh`, `impact`, `ding` (авто); `hit` (короткий удар на акцентное слово), `click`, `riser` (нарастание, пик в конце — ставить так, чтобы конец совпал с событием), `tension` (напряжение, сердцебиение, тревога), `camera`, `money`, `typing`, `paper`, `glitch`, `sparkle` (магия, появление), `question`, `wrong` (неправильный ответ), `beep` (цензура), `drum` (ба-дум-тсс, барабанная дробь), `rewind`, `crickets` (неловкая тишина), `crowd` (толпа, аплодисменты), `glass` (бокалы, тост, разбитое стекло), `boom` (1 взрыв + 1 бас-дроп), `fire` (пламя, зажигалка, горящая бумага), `vibe`, `ambience` (природа, дождь, вода — фоном, не авто).
- Между авто-эффектами минимум 0,5 с. Варианты в папке чередуются по кругу.
- Ручные эффекты на фразу: `"sfx": {"items": [{"at": "фраза", "sound": "cash", "volume": 0.8}]}`; отключить авто: `"auto": false`; общая громкость: `"volume": 0.5`.
- Слышать звук Claude не может — проверять по замерам громкости (`loudnorm`/`ebur128`) и картинке `showwavespic`/`showspectrumpic`, а не на слух.

**Настроение ролика** (`app/scripts/mood.mjs`, первая версия)
- Перед монтажом определить тему и эмоцию ролика и одной строкой сообщить пользователю (например, «вдохновение / позитив, сила 3 из 5»).
- Записать в edit-файл: `"mood": {"name": "inspire", "strength": 3}`. Варианты: `sad`, `energy`, `shock`, `calm`, `inspire`; сила 1–5.
- Настроение меняет цветокоррекцию (насыщенность, контраст, яркость, тёплый или холодный тон), камеру, плотность и громкость эффектов, громкость музыки.
- `"music": "auto"` берёт самый ровный трек (наименьший LRA, не короче ролика) из `music/<папка настроения>` (грусть, энергия, напряжение, спокойно, вдохновение).
- **Подбор музыки — сначала `music/INDEX.md`**: по каждому треку настроение, темп, длительность, уровень, описание. В корне папки настроения — инструменталы (включая переделанные хиты, флаг «хит» в индексе); `_вокал/` — с голосом, не брать под речь. Трек указывать явно: `"music": {"src": "<папка>/<файл>"}`.
- Явные `camera`, `sfx`, `music` в edit-файле важнее настроения.

**Скорость рендера**
- Каждое видео (рассказчик, реклама, вставки) перед монтажом автоматически сжимается в копию: 30 к/с, не больше 1080×1920, горизонтальные — не больше 1920×1080. Копия лежит в `app/public/`, делается один раз. Оригиналы в `input` не трогаются. **Ролик всегда 1080×1920** (решение пользователя 10.10), каким бы ни был исходник: вертикальные копии приводятся к 1080 по ширине (меньшие увеличиваются lanczos), графика и субтитры рисуются сразу в полном размере и остаются чёткими. Рендер 1080 примерно в 2,5 раза дольше 720 (≈1,9 с на секунду ролика). 
- **ИИ-улучшение слабого исходника** (решение пользователя 10.10; цель — обрабатывать видео как можно меньше):
  - Применять **только если исходник действительно низкого качества**: короткая сторона меньше 720 px (480p, 540p) или сильное сжатие, «кубики», мыло. Нормальное видео с телефона (720 и выше) не трогать — хватает обычного увеличения до 1080.
  - Сборка сама предупреждает: `⚠ низкое разрешение исходника…`. Тогда **сначала спросить пользователя**: «Видео в низком разрешении (W×H). Улучшить его ИИ перед монтажом? Займёт ≈N мин (≈0,5 с на кадр)». Без «да» — не улучшать.
  - После «да»: `npm run enhance -- "<файл из input>"` → копия рядом с оригиналом `<имя>.ai.mp4` (1080 по ширине, звук оригинала; оригинал не трогается), в edit-файле `inputs` указать её. Распознавание речи берётся с оригинала — фразы те же.
  - Модель — `4xLSDIRCompactC3` (Real-ESRGAN ncnn, `tools/realesrgan/`, в git не попадает): сохраняет фактуру кожи, не «пластик», не мерцает (проверено в TEST3.10). Для очень шумных, пережатых — `--model RealESRGAN_General_WDN_x4_v3`. `realesrgan-x4plus` не брать: в 10 раз медленнее и «полирует» лицо.
  - Лицензия LSDIR Compact — CC-BY 4.0, автор Phhofm (указывать, если спросят о модели); Real-ESRGAN — BSD-3.
- Мягкие тени и цветокоррекцию пока не трогать (решение пользователя 06.10).

**Прочее**
- `"output": "TEST3"` — своё имя готового файла.
- `"layout": {"topPct": 0.07}` — своя высота хука, карточек и плашек (по умолчанию 0.09).
- В субтитрах короткие предлоги и союзы склеиваются со следующим словом и не остаются в конце строки.
- Новшества проверяются на `input/Старые исходники/TestReels1.MP4` через `edits/test.json`. Каждый раз — следующий номер `TEST<n>`, прошлые не затирать. Тест записывается в таблицу «Тесты на TestReels1» в `ПЛАН РАЗВИТИЯ.md`.
- **Тестер** — отдельный мини-проект `tester/` (пользователю нравится — вид не менять без просьбы; описание — `tester/README.md`): все тесты синхронно, звук по клику, перемотка, покадрово, скорость; «Подробнее» под роликом — время сборки по этапам и замеры (из `output/<имя>.stats.json`, их пишет `build.mjs` при рендере); вкладка «План» — что уже добавили и что следует добавить. Запуск: `node tester/server.mjs` (в панели браузера — конфигурация «tester» в `.claude/launch.json`) → http://localhost:8765, и открыть в обычном браузере пользователя.
  - **После каждого нового теста** — добавить его в `output/tests.json` (`name`, `date`, `what`, `check`) и открыть тестер, чтобы пользователь сразу сравнил.
  - Когда что-то сделано или появилась идея — обновить `output/roadmap.json` (`done` с датой / `todo`).

## Техника
