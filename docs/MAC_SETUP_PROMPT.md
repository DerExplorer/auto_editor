# 1. Что это за проект

**auto_editor** — монтажёр вертикальных рилсов на Remotion (Node.js + React). Код лежит на GitHub: https://github.com/DerExplorer/auto_editor (ветка main).

Как он работает:
- faster-whisper локально распознаёт речь (Python, без API и ключей);
- по описанию монтажа `app/edits/<имя>.json` и текстовому слою субтитров `<имя>.subs.txt` собирается ролик: субтитры, заголовок-хук, плавная «камера», плашки, инфографика, реклама в рамке поверх рассказчика;
- рендер через `npx remotion render`.

Ты в этом проекте — **режиссёр монтажа**:
1. смотришь исходники;
2. пишешь edit-файл и текст субтитров;
3. запускаешь сборку;
4. проверяешь кадры;
5. отчитываешься мне.

Раньше всё это делал Claude на моём Windows-ПК. Теперь переезжаем на Mac.

# 2. Установка

Выполни по порядку и после каждого шага проверь, что всё получилось.

1. **Узнай систему:** `sw_vers`, `uname -m` (скорее всего Apple Silicon, arm64).

2. **Command Line Tools:** проверь `xcode-select -p`. Если их нет — `xcode-select --install`. Это окно с кнопкой: попроси меня нажать «Установить» и дождись.

3. **Homebrew:** проверь `brew -v`.
   - Если его нет — установи по инструкции с https://brew.sh.
   - Установщик попросит пароль администратора. **Пароль сам не вводи**: скажи мне, что в терминале нужен пароль, и подожди, пока я введу.
   - После установки выполни команды, которые Homebrew покажет в конце (добавление в PATH через `~/.zprofile`), и проверь `brew -v`.

4. **Инструменты:**
   ```bash
   brew install git node ffmpeg python@3.12
   ```
   Нужны именно Node ≥ 20 и Python 3.12. На более новых Python колёса ctranslate2/faster-whisper могут не собраться.

5. **Проект:**
   ```bash
   mkdir -p ~/dev && cd ~/dev && git clone https://github.com/DerExplorer/auto_editor.git && cd auto_editor/app
   ```

6. **Зависимости:**
   ```bash
   npm ci
   python3.12 -m venv .venv && source .venv/bin/activate && pip install --upgrade pip && pip install -r requirements.txt
   ```
   - Homebrew-Python запрещает ставить пакеты глобально, поэтому только venv.
   - Сборщик сам находит Python из активного venv (переменная `VIRTUAL_ENV`).
   - Перед каждой работой активируй venv: `source ~/dev/auto_editor/app/.venv/bin/activate`. Если удобнее — пропиши `export PYTHON=~/dev/auto_editor/app/.venv/bin/python` в `~/.zprofile`, тогда venv активировать не нужно.

7. **Рабочие папки:** `npm run setup` создаст `~/Desktop/Apps/auto_editor/input` и `output` и запишет пути в `app/local.json`.
   - Если macOS спросит доступ к «Рабочему столу» — попроси меня разрешить.
   - `local.json` в git не коммить.

8. **Проверка окружения:** `npm run doctor` — все пункты должны быть ✓. Если что-то ✗ — почини по подсказке.

9. **Смоук-тест:** `npm test` — полный прогон на тестовых клипах: распознавание, субтитры, графика, рендер mp4, проверка ffprobe.
   - В первый раз скачаются модель Whisper (~500 МБ) и headless Chrome для Remotion. Это нормально.
   - Все пункты должны быть ✓.
   - Посмотри 2–3 кадра готового `app/build/smoke/sample.mp4` (`ffmpeg -ss 1 -i ... -frames:v 1 x.png`). На них должны быть субтитры шрифтом Inter Tight, янтарная плашка и кольцо-инфографика.

10. **Если что-то падает** — разберись сам: прочитай ошибку, почини, повтори. Возможные места:
    - права на Рабочий стол;
    - PATH для brew;
    - venv не активирован;
    - `npm ci` ругается на lockfile — **не** делай `npm install` с обновлением версий. Версии Remotion зафиксированы специально: 4.0.528 для remotion, @remotion/cli, @remotion/fonts.

11. **Память:** прочитай `~/dev/auto_editor/CLAUDE.md` целиком — там все мои правила. Сохрани в свою память, что:
    - проект лежит в `~/dev/auto_editor`;
    - я кладу видео в `~/Desktop/Apps/auto_editor/input`;
    - результат ты кладёшь в `output`;
    - правила стиля — в `CLAUDE.md`.

12. **Отчёт:** в конце коротко:
    - что установлено и какие версии;
    - прошли ли `doctor` и `test`;
    - где папки input/output;
    - что пришлось чинить.

# 3. Как будем работать дальше

- Я кладу видео в `~/Desktop/Apps/auto_editor/input` (часто в подпапку на каждый ролик: рассказчик + реклама) и пишу в чате, какие файлы и что сделать.
- Ты:
  1. изучаешь материал:
     - `ffprobe` — размер, длительность;
     - транскрипция: `python scripts/transcribe.py <видео> <out.json>` или первая сборка, кэш в `app/build/cache`;
     - раскадровка через ffmpeg `tile` — где лицо, какие сцены;
     - смены сцен во вставке: `select='gt(scene,0.25)'`;
  2. пишешь `app/edits/<имя>.json` (образцы в репо: `apple.json`, `doritos2.json`, `reel2.json`, `testreels1.json`, `sample.json`) и **переписываешь по смыслу** `app/edits/<имя>.subs.txt` (черновик создаётся сам);
  3. `npm run build -- edits/<имя>.json` → убираешь предупреждения «не влезет в 2 строки», проверяешь стоп-кадры:
     `npx remotion still src/index.ts Edit out.png --frame=N --props=build/<имя>/9x16.props.json --scale=0.4`;
  4. `npm run render -- edits/<имя>.json` → готовый `output/<имя>.mp4`. Проверяешь кадры уже из mp4 и присылаешь отчёт: путь, что сделано, что упрощено.
- Прошлые результаты не затирай: новая версия — новое имя, если я не попросил перезаписать.
- Коммитить и пушить в GitHub — только когда я попрошу. Видео, `app/build/`, `app/local.json` в git не попадают.

Все времена в edit-файле — привязки к фразам речи, а не секунды:
- `"start": "Вопрос второй"`;
- `{"phrase": "ответ В", "after": "Вопрос третий", "edge": "end", "offsetMs": 300, "nth": 1}`;
- `{"ms": 3000}` — точное время.

Основные поля edit-файла:
- `inputs`
- `cut`: `{"removePauses": false, "removeRetakes": false}`, если видео уже нарезано
- `focus`
- `hook`: `words` с `size` s/m/l/xl, `accent`, `br`, а также `topPct`
- `titles`: плашки
- `cards`: карточки вопросов
- `broll`: `ring`/`bars`/файл, `mode` full/pip
- `inset`: видео в рамке — `src`, `volume`, `topPct`, `widthPct`, `borderColor`, `pieces` [{`at`: фраза, `from`: секунда вставки}], `end`
- `subtitles`: `bottomPct`, `underInsetBottomPct`, `maxWidthPct`
- `bottomGradient`
- `camera`

# 4. Мои правила стиля (обязательны по умолчанию; то же самое есть в CLAUDE.md)

**Формат**
- Только вертикаль 9:16 в исходном разрешении.
- Без логотипа, без полноэкранных заставок в начале и конце.
- Если видео уже нарезано мной — авто-нарезку не делать.

**Хук**
- Заголовок первые ~3 секунды, КАПСОМ, слова разного размера: сильнее акцент — крупнее, главное слово — на янтарной плашке.
- Слова въезжают по одному сверху.
- Если сверху лицо — хук в средней зоне кадра (`hook.topPct` ≈ 0.5–0.56).

**Субтитры**
- До 2 строк, всегда самый верхний слой.
- Текущее произносимое слово — янтарное `#FFC163`, остальные сплошные белые.
- Никакой прозрачности, подпрыгиваний, свечения.
- Текстовый слой:
  - маленькие буквы, без точек;
  - цифры всегда цифрами;
  - КАПС целым словом — только для очень сильных акцентов;
  - заглавные буквы — только где нужно по смыслу (буквы вариантов, имена, бренды), не в начале фразы;
  - варианты пишутся «вариант А. 20%», «А. удвоилась».
- Блоки делить по смыслу: одна мысль — один блок, не слишком большие, не рубить.
- Нумерация («номер 4», «вопрос второй») → в месте субтитров только большая цифра: строка `[4] номер 4`.
- Исправлять ошибки распознавания: Whisper путает «Б» и «в», коверкает бренды (Doritos, reels, Apple).

**Лицо и безопасные зоны** (схема: `app/docs/reels-safe-zones.webp`, для 1080×1920)
- Никогда не перекрывать лицо. Волосы, особенно их верхнюю часть, — можно.
- Всё важное — внутри безопасных зон:
  - по бокам ≥70 px (не прижимать к краям — это важнее всего);
  - снизу 250 px и полоса подписи ≈76–87% высоты;
  - справа в нижней половине колонка кнопок 170 px.
- Верхние элементы (хук, карточки, плашки) — примерно на 5% сверху или чуть ниже.
- Внизу — лёгкий тёмный градиент под субтитры, не доходящий до лица.

**Камера**
- База всегда 100%.
- Время от времени плавный наезд до ~107%, держать хотя бы пару секунд, плавно вернуть.
- Никаких быстрых «полётов» туда-сюда.

**Графика** (дизайн-система каруселей)
- Шрифты Inter Tight (заголовки) + Inter (текст), уже лежат в `app/public/fonts`.
- Цвета:
  - чернила `#111317`, текст `#2B2D33`, фон `#FAFAFA`, серый `#DCDCDC`;
  - один акцент — янтарь `#FFC163` (глубже `#F5A742`);
  - на янтаре только чёрный текст;
  - второго яркого цвета нет.
- Плашки-«таблетки» с наклоном −3°.
- У всей графики мягкая размытая тень и скругления.
- Полноэкранная инфографика — действительно на весь экран; смысл выше нижней трети, там субтитры. Субтитры не перекрывают важный текст инфографики.

**Реклама / видео в рамке поверх рассказчика**
- Рамка чуть ниже середины кадра, сразу под подбородком, со скруглёнными углами и оранжевой обводкой `#F5A742`. Пропорции берутся из самого видео.
- Звук вставки очень тихий, ~5%: слышно в основном рассказчика.
- Субтитры под рамкой. Когда рассказчик переходит к общей теме, рамка уходит, субтитры поднимаются на её место.
- Нарезка вставки:
  - резать только если момент рекламы действительно подкрепляет конкретную фразу; если реклама монотонная или речь описывает её в целом — пусть идёт непрерывно;
  - **никогда не перематывать назад** на уже показанные кадры, кроме случаев, когда по сценарию «посмотрите ещё раз»;
  - резать только вперёд и только чтобы пропустить заметный кусок (секунды, не доли) — микро-скачки выглядят дёргано;
  - склейки ставить на собственные смены сцен рекламы;
  - в рекламе обычно много важных моментов — резать мало и аккуратно;
  - не показывать чёрные кадры и затемнения рекламы (начало, после логотипа).

**Типичная концовка** в моих роликах: «эта реклама собрала миллионы просмотров… это reels… пиши СТРАТЕГИЯ». На неё — плашка «пиши «стратегия»» в средней зоне.

Начинай с раздела 2. Когда всё установлено и проверено — пришли отчёт и жди моих видео.
