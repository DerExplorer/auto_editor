# Палитра клиента

Клиент называет любимые цвета → `npm run palette` превращает их в **роли** для графики ролика. Сам ролик остаётся в нашей дизайн-системе (Inter Tight + Inter, светлые карточки, мягкие тени, плашки −3°), меняются только цвета.

```bash
npm run palette -- "#E8B4B8" "#6B4E71" --client anna-brows      # первый цвет — главный
npm run palette -- "#DCDCDC" "#2E8B57" --accent 2 --client ivan # главный — второй
npm run palette -- "#1F3A5F"                                    # просто посмотреть, без записи
```

Результат: роли в консоли, `clients/<имя>/brand.json` → `palette`, превью `clients/<имя>/palette.html` (хук, субтитры, карточка, квиз, рамка).

## Роли

| Роль | Где в ролике | Как получается |
|---|---|---|
| `accent` | плашка главного слова хука, плашки-таблетки, горящий вариант квиза, последний столбик, кольцо | главный цвет клиента; бледный усиливается по насыщенности (оттенок тот же) |
| `onAccent` | текст на акценте | тёмный или белый — что контрастнее (цель ≥ 4.5:1) |
| `accentDeep` | обводка видео в рамке, глубокие акценты | акцент темнее на ступень |
| `highlight` | текущее слово субтитров, большая цифра, буквы вариантов на тёмном | акцент, осветлённый до контраста ≥ 7:1 с тёмным видео |
| `ink`, `text`, `muted` | заголовки и текст на карточках | почти чёрный / графит / серый, **чуть подкрашенные в оттенок акцента** — тёплые для тёплого, холодные для холодного |
| `bg`, `grey`, `blob` | фон карточек, неактивные столбики, подложки | почти белый и светло-серые в том же оттенке |
| `support` | **только обложки, аватарка, промпты** | остальные любимые цвета клиента как есть |
| `words` | промпты | английские названия + hex: `soft pink (#E8B4B8)` |

## Правила

1. **В видео один акцент.** Второй цвет клиента в графику ролика не идёт — он живёт на обложках, аватарке, фонах. Два ярких цвета в рилсе спорят с лицом и субтитрами.
2. **Цвет клиента не подменяем, а адаптируем.** Оттенок сохраняется всегда; меняются только светлота и насыщенность, если цвет не работает на видео. Исходный цвет остаётся в `source` и в `words`.
3. **Подсветка слова должна отличаться от белого.** Бледные цвета (пудровый, шампань, мята) рядом с белыми субтитрами не видны → скрипт усиливает их. Тёмные (тёмно-синий, бордо, изумруд) не видны на тёмном градиенте → `highlight` светлее.
4. **Текст на акценте — только `onAccent`.** Для янтаря, жёлтого, пудрового — тёмный; для синего, бордо, изумруда — белый.
5. **Нейтрали в оттенок акцента.** Чистый серый `#DCDCDC` рядом с тёплым персиковым выглядит грязно; подкрашенный — «дорого».
6. **Красный и зелёный как акцент** читаются как «ошибка / правильно». Если клиент любит красный — для квиза всё равно работает (правильный ответ горит акцентом), но в инфографике не подписывать красным «плохие» цифры.
7. **Цвет кожи.** Оранжево-персиковые акценты рядом с лицом сливаются с кожей; лучше чуть глубже или чуть насыщеннее — проверить на кадре с лицом.

## Как проверять

1. Открыть `clients/<имя>/palette.html`: плашка читается? слово в субтитрах отличается от белого? карточка не «серая грязь»?
2. Прочитать заметки `!` в выводе скрипта — там всё, что пришлось поправить.
3. Стоп-кадр реального ролика с `"client": "<имя>"` (хук + субтитры + карточка): `npx remotion still …`.
4. Если клиент говорит «не мой цвет» — поменять порядок цветов или `--accent`, либо вручную поправить роль в `brand.json` (скрипт её перезапишет при следующем запуске — тогда записать причину в `profile.md`).
