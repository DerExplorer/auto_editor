# Стиль клиента — с чего начинается работа

Перед первым роликом нового клиента Claude собирает его **паспорт стиля**: кто он, для кого снимает, как должен выглядеть, какие у него цвета и какие промпты дают хорошие картинки. Дальше все ролики, обложки и аватарки делаются по паспорту.

```
 материалы клиента  →  анкета и выводы  →  палитра  →  паспорт  →  промпты (аватарка, обложки, фоны)
 (аккаунт, фото,        (кто, для кого,      npm run     clients/     docs/style/prompting.md
  любимые цвета)         ниша, настроение)    palette     <имя>/       docs/style/covers.md
```

## Где что лежит

| Файл | Что внутри |
|---|---|
| `docs/style/README.md` | этот порядок работы |
| `docs/style/niches.md` | справочник ниш: что показывать в кадре кроме самого человека, свет, фактуры, клише |
| `docs/style/prompting.md` | как писать промпты для генерации картинок, по моделям |
| `docs/style/covers.md` | обложки рилсов и аватарки: композиция, текст, безопасные зоны |
| `docs/style/palette.md` | как из любимых цветов получается палитра и как её проверять |
| `docs/style/client-template/` | пустой паспорт (`profile.md` + `brand.json`) |
| `clients/<имя>/` | паспорта клиентов (в git не попадают): `profile.md`, `brand.json`, `palette.html` |

`<имя>` — латиницей, коротко: `anna-brows`, `ivan-realty`.

## Порядок (20–30 минут)

### 1. Собрать материал

Пользователь даёт что есть: ссылку на аккаунт или скриншоты, 2–5 фото клиента, описание бизнеса, любимые цвета (словами или hex), примеры того, что клиенту нравится и не нравится. Чего нет — Claude не выдумывает, а помечает в паспорте как допущение.

### 2. Понять клиента — анкета

Ответы складываются из материалов; спрашивать пользователя только то, что не видно. Главные вопросы:

1. **Что продаёт на самом деле?** Не услугу, а результат и чувство. Брови → «проснулась и уже красивая». Недвижимость → «безопасная сделка и своя квартира».
2. **Кто зритель и что у него болит?** Возраст, доход, город, страхи, желания.
3. **Уровень цены:** эконом · средний · премиум · люкс. От этого зависит всё: свет, фактуры, плотность текста, количество графики. Чем дороже — тем меньше элементов, больше воздуха, мягче свет, спокойнее монтаж.
4. **Личность в кадре:** 3 слова (тёплая, строгая, ироничная, дерзкая, заботливая, экспертная…).
5. **Чем отличается от соседей по нише?** Это то, что надо визуализировать в первую очередь.
6. **Что нельзя:** клише ниши (см. `niches.md`), то, что клиенту не нравится, требования площадок и закона (медицина, финансы).
7. **Целевое действие:** записаться, написать, подписаться, купить.

### 3. Вывести стиль

По нише из `niches.md` + ответам — одна строка стиля и набор:

- **настроение по умолчанию** (`calm`, `inspire`, `energy`…; сила 1–5) — в `brand.json` → `defaults.mood`;
- **свет** — один на всё: мягкий дневной / студийный / тёплый вечерний / контрастный;
- **3–5 предметов** ниши, которые будут повторяться в кадре, на аватарке и обложках;
- **фактуры и фон**;
- **запреты**.

Правило выбора предметов: предмет должен **рассказывать про результат или экспертизу**, а не просто «быть про нишу». Кисти и пинцет у бровиста — про процесс; зеркало с отражением ухоженного лица — про результат. Лучше 1 сильный предмет, чем 5 случайных.

### 4. Палитра

```bash
npm run palette -- "#E8B4B8" "#6B4E71" --client anna-brows
```

Первым ставить цвет, который клиент любит больше всего (или `--accent 2`). Скрипт пишет роли цветов в `clients/<имя>/brand.json`, создаёт `profile.md` из шаблона и превью `palette.html` (как палитра выглядит на хуке, субтитрах, карточке, рамке). Подробности и проверка — `palette.md`. Цвета словами клиента («пудровый», «изумруд», «как у Тиффани») Claude сам переводит в hex.

### 5. Паспорт

Заполнить `clients/<имя>/profile.md`: кто, зритель, стиль, цвета, **стиль-блок для промптов** и готовые промпты (аватарка, шаблон обложки, фоны). Стиль-блок — 1–2 строки на английском, которые вставляются в каждый промпт этого клиента, чтобы все картинки были «из одной серии».

### 6. Показать пользователю

Коротко в чате: «кто клиент» одной строкой, стиль одной строкой, палитра (путь к `palette.html`), 2–3 промпта. Правки → в паспорт, раздел «Заметки», версия +1.

### 7. Монтировать по паспорту

В edit-файле: `"client": "anna-brows"`. Сборка берёт палитру клиента (акцент плашек и хука, подсветка слова в субтитрах, карточки, обводка рамки) и его настроение и музыку по умолчанию, если в edit-файле они не заданы.

## Что Claude делает сам, а что спрашивает

- Сам: ниша, предметы, свет, настроение, палитра из названных цветов, промпты.
- Спрашивает: только то, что меняет результат и не видно из материалов — уровень цены, если неясен; что клиенту точно не нравится; любимые цвета, если не названы.
- Никогда не выдумывает факты о клиенте для текста на картинках (цифры, награды, стаж).
